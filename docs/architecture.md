# Architecture — `floodcap-ew`

- `floodcap_ew.hydrology`: Antecedent Precipitation Index (`API`) soil-saturation decay, trapezoidal Manning open-channel stage-discharge hydraulics, 4-tier flood severity engine, OASIS CAP v1.2 XML alert serializer (`xml.etree.ElementTree`), and GSM-7 `<=160`-char community evacuation SMS generator.
- `floodcap_ew.cli`: River Nyamwamba flash-flood simulation CLI (`--xml` or JSON).
